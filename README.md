# Logistic-Regression-Model

This repository contains an implementation of a **Logistic Regression** model using Python.  
The project demonstrates the complete machine learning workflow, including data preprocessing, model training, prediction, and evaluation.

## Contents
- `Logistic_Regression_Model.ipynb` – Jupyter Notebook with step-by-step implementation
- `Logistic_Regression_Model.html` – Exported HTML version of the notebook for easy viewing
- `README.md` – Project documentation

## Key Concepts Covered
- Logistic Regression for classification
- Train-test split
- Feature scaling
- Model evaluation using accuracy and classification metrics

- Python
- NumPy
